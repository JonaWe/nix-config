# Fluxer Voice Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run Fluxer on `ant`, reachable only on the tailnet at `fluxer.ts.pinkorca.de`, with working voice.

**Architecture:** A NixOS module pins Fluxer's upstream Docker Compose bundle in the store and runs it from a oneshot systemd unit, layering a Nix-generated override file (ZFS bind mounts, tailnet-only LiveKit ports) and two env files (Nix settings + sops secret). nginx fronts the bundle's edge on `127.0.0.1:8080`.

**Tech Stack:** NixOS 26.05, Docker 29.5 / Compose 5.1.4 on `ant`, sops-nix, ZFS + sanoid + restic, nginx.

**Spec:** `docs/superpowers/specs/2026-11-02-fluxer-design.md`

## Global Constraints

- Bundle: `https://github.com/fluxerapp/fluxer/releases/download/fluxer-release%402026.1102.171206/fluxer-compose-2026.1102.171206.tar.gz`, `fetchzip` with `stripRoot = false`, `hash = "sha256-+EcOnXlplSokUFNqaKlQDtNSvoUIDcAKQSoVQMfB7Zg="`.
- Compose project name `fluxer`; file order `docker-compose.yml`, `docker-compose.proxy.yml`, override.
- Domain `fluxer.ts.pinkorca.de`; edge bind `127.0.0.1:8080`; tailnet IP `100.64.0.2`.
- Data under `/opt/services/fluxer`, dataset `zdata/enc/services/fluxer` (`mountpoint=legacy`).
- Secret: `sops.secrets."fluxer/env"`. Never edit `../nix-secrets`.
- Build and switch on `ant` only, over SSH as root with `--flake path:`.
- Files stay terse; rationale goes in commit messages. Commits carry no Co-Authored-By / Claude-Session trailers. Message style: gitmoji prefix (`:sparkles:`, `:bug:`, …).
- Only stage files this plan touches. `flake.lock` already carries unrelated user changes: stage only the `mysecrets` hunk.

## Review Focus

- LiveKit media ports published on `0.0.0.0` (docker bypasses the NixOS firewall) — must be bound to `100.64.0.2` only. Pinned by Task 2 Step 1 eval and Task 3 `ss` check.
- Unit starting before the ZFS dataset is mounted, writing postgres data onto the root fs underneath. Pinned by `RequiresMountsFor` eval in Task 2.
- Duplicate or client-forged `X-Forwarded-For` reaching Fluxer because `recommendedProxySettings` also sets it. Pinned by Task 2 nginx config grep.
- Config change (bundle bump, override, secret rotation) applied by `switch` without the stack restarting. Pinned by `restartTriggers` / `restartUnits` eval in Task 2.
- Fluxer dataset missing from the offsite restic job. Pinned by Task 1/2 `ZFS_DATASETS` eval.

### Task 2: Fluxer module

**Files:**
- Create: `modules/services/fluxer/fluxer.nix`
- Modify: `modules/services/default.nix` (add `./fluxer/fluxer.nix`)
- Modify: `hosts/ant/default.nix` (`myconf.services.fluxer.enable = true;`)

**Interfaces:**
- Consumes: `homelab.extraBackupDatasets` (Task 1).
- Produces: `myconf.services.fluxer.enable`; systemd unit `fluxer.service`; nginx vhost `fluxer.ts.pinkorca.de`.

Module contents (`let cfg = config.myconf.services.fluxer`, `lib.mkIf cfg.enable`):

- `bundle = pkgs.fetchzip { … }` per Global Constraints.
- `settings = pkgs.writeText "fluxer.env" ''…''` with exactly:
  `FLUXER_SETTINGS_LOADED=true`, `FLUXER_DOMAIN`, `FLUXER_EDGE_BIND=127.0.0.1:8080`, `FLUXER_LIVEKIT_USE_EXTERNAL_IP=false`, `FLUXER_LIVEKIT_NODE_IP=100.64.0.2`, and the memory table from the spec's *Resources* section verbatim.
- `override = pkgs.writeText "fluxer.override.yml" ''…''` (text, not `toJSON` — it needs the `!override` tag):
  - per-service `volumes:` entries binding `/opt/services/fluxer/<dir>` onto the same container path as the bundle's named volume: postgres → `/var/lib/postgresql/data`, valkey → `/data`, nats → `/data`, meilisearch → `/meili_data`, seaweedfs → `/data`, edge → `/data` (`edge-data`) and `/config` (`edge-config`). Compose merges service volumes by container path, so these replace the named ones.
  - `livekit.ports: !override` with `"100.64.0.2:7881:7881"` and `"100.64.0.2:7882:7882/udp"`.
- `compose = "docker compose -p fluxer -f ${bundle}/docker-compose.yml -f ${bundle}/docker-compose.proxy.yml -f ${override} --env-file ${settings} --env-file ${config.sops.secrets."fluxer/env".path}"`.
- `sops.secrets."fluxer/env".restartUnits = ["fluxer.service"];`
- `systemd.services.fluxer`: `after`/`requires = ["docker.service"]`, `wantedBy = ["multi-user.target"]`, `path = [config.virtualisation.docker.package]`, `unitConfig.RequiresMountsFor = ["/opt/services/fluxer"]`, `restartTriggers = [bundle settings override]`, `serviceConfig = { Type = "oneshot"; RemainAfterExit = true; TimeoutStartSec = "30min"; ExecStart = "${compose} up -d --remove-orphans --wait"; ExecStop = "${compose} down"; }`.
- `systemd.tmpfiles.rules`: `d` for `/opt/services/fluxer/{postgres,valkey,nats,meilisearch,seaweedfs,edge-data,edge-config}`, `0750 root root`.
- `fileSystems."/opt/services/fluxer" = { device = "zdata/enc/services/fluxer"; fsType = "zfs"; };`
- `services.sanoid.datasets."zdata/enc/services/fluxer".useTemplate = ["default"];`
- `homelab.extraBackupDatasets = ["zdata/enc/services/fluxer"];`
- `services.nginx.virtualHosts."fluxer.ts.pinkorca.de"`: `useACMEHost = "pinkorca.de"`, `forceSSL`, `http2`; `locations."/"` with `proxyPass = "http://127.0.0.1:8080"`, `proxyWebsockets = true`, `recommendedProxySettings = false`, and `extraConfig` setting `Host $host`, `X-Real-IP $remote_addr`, `X-Forwarded-For $remote_addr`, `X-Forwarded-Proto $scheme`, `X-Forwarded-Host $host`, `client_max_body_size 512m`, `proxy_read_timeout 3600s`, `proxy_send_timeout 3600s`, `proxy_buffering off`, `proxy_request_buffering off`.
